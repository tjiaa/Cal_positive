# Positive Selection Analysis Pipeline

This repository contains an automated Python pipeline (`positive_selection_pipeline.py`) designed to detect positive selection in coding sequences (CDS) using PAML (codeml).

## Overview

The pipeline automates the following steps:
1. **Validation & Translation**: Validates input CDS sequences (checks for multiple of 3 length and valid stop codons), translates them into amino acid sequences.
2. **Alignment**: Aligns the amino acid sequences using MAFFT.
3. **Back-translation**: Creates a codon-aware nucleotide alignment from the amino acid alignment and original CDS.
4. **Phylogeny Construction**: Infers a maximum-likelihood tree using FastTree from the codon alignment.
5. **Positive Selection Testing**: Runs PAML `codeml` comparing the M7 (null model, no positive selection) and M8 (alternative model, allows positive selection) site models.
6. **Statistical Analysis & Reporting**: Performs Likelihood Ratio Tests (LRT) to determine significance and extracts positively selected sites (BEB posterior probability > 95%) from the M8 output, generating a concise final report.

## Input

The script accepts either a single FASTA file or a directory containing multiple FASTA files.
**Crucial Requirement**: Each FASTA file must represent **one gene family** containing homologous CDS sequences from different species/strains. The sequences must be in-frame coding sequences (CDS) as annotated by tools like Bakta.

## Dependencies

The script relies on several external bioinformatics tools and Python libraries.

### External Software
- **MAFFT**: For multiple sequence alignment.
- **FastTree**: For building phylogenetic trees.
- **PAML (codeml)**: For detecting positive selection.

You can easily install these via Conda:
```bash
conda create -n positive_selection -c bioconda mafft fasttree paml
conda activate positive_selection
```

Alternatively, on Ubuntu/Debian systems:
```bash
sudo apt-get update
sudo apt-get install mafft fasttree paml
```

### Python Packages
The pipeline requires Python 3.6+ and the following packages:
- `Biopython`
- `SciPy`

Install them via pip:
```bash
pip install biopython scipy
```

## Usage

Run the script on a single FASTA file:
```bash
python positive_selection_pipeline.py -i input_gene.fasta -o output_directory
```

Run the script on a directory containing multiple FASTA files (batch mode):
```bash
python positive_selection_pipeline.py -d input_directory -o output_directory
```

## Output Structure

The output directory will contain organized subfolders:
- `alignments/`: Contains the intermediate protein alignments and final codon-aware nucleotide alignments.
- `trees/`: Contains the phylogenetic trees generated by FastTree.
- `paml_logs/`: Contains the raw output logs and control files from `codeml` (both M7 and M8).
- `reports/`: Contains the final parsed and summary report(s) of the positive selection test, detailing p-values and positively selected sites.
